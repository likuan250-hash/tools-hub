# 网盘查重工具设计（待实现）

## 目标
在网盘转台中按文件夹名查重（匹配中文/英文），列出分组让用户勾选删除整个文件夹。

## 交互
1. 入口：网盘转台面板新增「查重」工具，选网盘（百度/夸克/迅雷）→ 选目录。
2. 查重：列出选中层的文件夹名（`listSubfolders`，需补翻页），规范化匹配分组。
3. 展示：每组列出成员文件夹名+大小/时间，用户勾选要删的文件夹。
4. 删除：勾选确认后按文件夹 ID 整体删除（网盘侧连带子内容，进回收站），删除前二次确认清单。

## 匹配规则（三层，从严到宽）
- L1 规范化相等：去空格/标点/全半角差异（`正当防卫4` = `正当防卫 4`）。
- L2 剥版本后缀后相等：内置可编辑后缀表（中文：官方中文/全DLC/免安装/硬盘版/学习版/免费/完整版/破解版/绿色版/豪华版/终极版/年度版；英文：edition/complete/deluxe/reloaded/cracked/repack/goty/ultimate），数字编号归一。
- L3 中英对照表：`正当防卫4` ↔ `Just Cause 4`，内置常见游戏表 + 用户可手动补映射；未消化的变体列出让用户决定。
- 不自动处理：系列名差异（`三国无双7` vs `真三国无双7`）、年份/副标题，仅靠对照表或忽略。

## 范围与边界
- 只查选中层的文件夹，不递归子层、不匹配子文件。
- 同名文件夹算重复（游戏目录结构下即重复转存产物）。
- 忽略清单：误报组可点忽略，跨会话保存（本地配置，不进 git）。

## 待补底层能力
- 三家删除接口（百度 `filemanager?opera=delete` 等，传文件夹 ID，回收站优先）。
- 三家 `listSubfolders` 翻页。
- 查重结果分组纯函数 + 规范化/后缀表/对照表匹配。

## 安全约束
- 删除必须二次确认（列明待删清单），禁止一键全删。
- 优先回收站删除；无回收站参数时明示"永久删除"。
